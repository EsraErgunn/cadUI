# StarCAD Prototip

StarCAD Prototip, modern web teknolojileri kullanılarak geliştirilen 2D ve 3D CAD uygulamasıdır.

## Özellikler

- 2D çizim araçları
- 3D model görüntüleme
- TypeScript tabanlı mimari
- React Compiler desteği

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
